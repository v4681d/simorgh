Design principles

Show the signal path

Audio routing is always visible as chips with arrows. Every chip is clickable and jumps to its setting — no hidden state.

Prove, don’t promise

Live meters and real latency numbers wherever audio flows. Never a bare “Running” label the user has to trust blindly.

Partial → final

Streaming text appears provisionally at reduced opacity and solidifies when finalized. Finalized text never rewrites or flickers.

RTL is first-class

Persian gets proper shaping, fonts, and right-aligned columns — and the whole UI mirrors when the app language is Persian.
